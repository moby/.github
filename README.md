# moby/.github

Community health files and shared documents for the Moby and Docker open
source organizations.

## AI Usage Policy

[AI_POLICY.md](AI_POLICY.md) is the shared AI usage policy for Moby and
Docker open source projects.

Repos can link to it directly, or keep a synced copy next to their own
`CONTRIBUTING.md` / `AGENTS.md`. They can also tighten any rule in it to
fit their own workflow, for example requiring a maintainer-approved issue
before an AI-assisted PR gets accepted (see
[Approved issues for AI-assisted PRs](AI_POLICY.md#approved-issues-for-ai-assisted-prs)).
If a repo's own policy is stricter, follow that one instead; the shared
policy is the floor, not the ceiling.
